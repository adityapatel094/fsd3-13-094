# FS (file system) Node JS's Module

It Direct connect with client Os rather than brwoser.

## major task of Fs Module

- Reading and writing files
  - readfile()
  - writefile()
  - appendfile()
- Directioary management
  - mkdir()
  - rmdir()
  - readdir()
- Metadata/Information
  - lstat()
  - fstat()
- watching for changes
  - watch()
  - watchfile()
  - unwatchfile()
- streaming Large file
  - createReadstream()
  - createWritestream()
- File Operations
  - rename()
  - truncate()
  - unlink()
  - link()
  - syslink()
